# Palmistry & Tarot Intelligence Platform - Team 1

This repository contains the AI Palmistry and Tarot Card Intelligence platform built with React, Vite, and FastAPI.

## Getting Started

### Frontend
- Install dependencies: `npm install`
- Run development server: `npm run dev`

### Backend
- Navigate to `backend/` directory
- Install requirements and start server: `python -m uvicorn main:app --reload`
